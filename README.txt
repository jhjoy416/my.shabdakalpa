শব্দকল্প – ফোনে অ্যাপ হিসেবে ইনস্টল

১. এই ফোল্ডারের সব ফাইল (index.html, manifest.webmanifest, sw.js, icons/) যেকোনো HTTPS হোস্টিংয়ে আপলোড করুন
   (যেমন Netlify Drop, GitHub Pages, Cloudflare Pages – সবই বিনামূল্যে)।
২. ফোনে লিংকটি খুলুন:
   - Android (Chrome): ⋮ মেনু → "Install app" / "Add to Home screen"
   - iPhone (Safari): Share → "Add to Home Screen"
৩. প্রথমবার খোলার পর ফন্ট ও লাইব্রেরি ক্যাশ হয়, এরপর ইন্টারনেট ছাড়াও চলবে।

লেখা ফোনের ব্রাউজার/অ্যাপের লোকাল স্টোরেজে থাকে। PDF বাটনে চাপলে PDF ডাউনলোড হয়।
